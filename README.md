# SOTEC Service Web

Sitio corporativo inicial construido con Next.js, TypeScript y Tailwind CSS.

## Ejecutar localmente

```bash
npm install
npm run dev
```

Abre `http://localhost:3000`.

## Publicar en Vercel

1. Sube esta carpeta a un repositorio nuevo de GitHub.
2. En Vercel, importa el repositorio y conserva los valores detectados.
3. Añade `NEXT_PUBLIC_WHATSAPP_URL` en las variables de entorno.

## Primeros cambios recomendados

- Actualiza el número de WhatsApp en `.env.local`.
- Sustituye las imágenes de muestra por fotos propias.
- Ajusta servicios, catálogo y enlaces de redes sociales.
